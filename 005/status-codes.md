# Response Status Codes

## 1xx (Informational):

The server has received the request and is continuing the process. Example: 100 Continue.

## 2xx (Success):

The request was successfully received, understood, and accepted. Example: 200 OK.

## 3xx (Redirection):

Further action needs to be taken by the client to complete the request, usually by going to a new address. Example: 301 Moved Permanently.

## 4xx (Client Error)

: The request contains bad syntax or cannot be fulfilled due to an issue on the client side. Example: 404 Not Found.

## 5xx (Server Error)

: The server failed to fulfill a valid request due to an error on the server side. Example: 500 Internal Server Error.
