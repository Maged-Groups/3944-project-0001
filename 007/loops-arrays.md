# PHP Loop Challenges

## Challenge 1: Count with a `for` Loop

Create a PHP script that uses a `for` loop to print the numbers from `1` to `20`.

## Challenge 2: Count Backward with a `for` Loop

Create a PHP script that uses a `for` loop to print the numbers from `10` down to `1`.

## Challenge 3: Calculate a Sum with a `for` Loop

Create a PHP script that uses a `for` loop to calculate and print the sum of the numbers from `1` to `100`.

## Challenge 4: Print Even Numbers with a `while` Loop

Create a PHP script that uses a `while` loop to print all even numbers from `2` to `30`.

## Challenge 5: Count in Steps with a `while` Loop

Create a PHP script that uses a `while` loop to print the numbers from `5` to `50`, increasing by `5` each time.

## Challenge 6: Run a `do...while` Loop

Create a PHP script that uses a `do...while` loop to print the numbers from `1` to `10`.

## Challenge 7: Execute at Least Once

Create a PHP script with a `do...while` loop whose condition is initially false. Print a message inside the loop and observe how many times the loop body executes.

## Challenge 8: Print Array Values with a `for` Loop

Create an indexed array containing five city names. Use a `for` loop to print each city on a separate line.

## Challenge 9: Calculate the Total of Array Values

Create an indexed array containing these numbers: `12`, `8`, `25`, `10`, and `5`. Use a `for` loop to calculate and print their total.

## Challenge 10: Find the Largest Number in an Array

Create an indexed array containing at least six numbers. Use a `for` loop to find and print the largest number in the array.

## Challenge 11: Print Array Values in Reverse

Create an indexed array containing five favorite movies. Use a `for` loop to print the movie names in reverse order.

## Challenge 12: Display Product Names and Prices

Create an indexed array containing at least five product names and a second indexed array containing their prices in the same order. Use a `for` loop to print each product name alongside its price.
