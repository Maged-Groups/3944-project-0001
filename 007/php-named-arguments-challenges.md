# PHP Named Arguments Challenges

## Challenge 1: Print User Information

Create a PHP function called `printUserInfo()` that accepts `name`, `age`, and `job`, then prints all three values.

Call the function using named arguments.

## Challenge 2: Calculate the Final Price

Create a PHP function called `calculatePrice()` that accepts `price`, `tax`, and `discount`, then returns the final price by adding the tax and subtracting the discount.

Call the function using named arguments in a different order from the function definition.

## Challenge 3: Create a User

Create a PHP function called `createUser()` that accepts `name`, `role`, and `active`.

Set the default value of `role` to `"user"` and the default value of `active` to `true`.

Call the function using named arguments while skipping the `role` argument.

## Challenge 4: Display Product Details

Create a PHP function called `displayProduct()` that accepts `name`, `price`, `quantity`, and `category`.

Print all the product details, then call the function using named arguments in a different order from the function definition.

## Challenge 5: Calculate Employee Salary

Create a PHP function called `calculateSalary()` that accepts `basicSalary`, `bonus`, and `deduction`.

Set the default values of `bonus` and `deduction` to `0`.

Return the final salary by adding the bonus to the basic salary and subtracting the deduction.

Call the function using named arguments, providing only `basicSalary` and `deduction`.

## Challenge 6: Book a Trip

Create a PHP function called `bookTrip()` that accepts `destination`, `days`, `travelClass`, and `includeHotel`.

Set the default value of `travelClass` to `"Economy"` and the default value of `includeHotel` to `true`.

Print the trip details, then call the function using named arguments in a different order from the function definition. Skip one optional argument to use its default value.
