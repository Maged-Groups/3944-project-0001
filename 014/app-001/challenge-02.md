# OOP Challenge: Gym Management System

## Project Overview

Create a PHP application to manage a fitness company that has multiple branches.

Each branch has its own members, subscriptions, revenue, and expenses.

The company also needs to track the overall statistics of all its branches.

Your task is to build this system using PHP OOP concepts.

---

## 1. Create the Gym Class

Create a class called `Gym` inside the `App\Company` namespace.

## 2. Define Class Constants

Create the following constants to represent subscription prices:

| Constant | Value |
|---|---:|
| MONTHLY_PRICE | 500 |
| QUARTERLY_PRICE | 1350 |
| YEARLY_PRICE | 4800 |
| PERSONAL_TRAINING_PRICE | 200 |

Use these constants whenever you calculate subscription prices.

---

## 3. Define Non-static Properties

Create the following private properties:

- `name`: Branch name.
- `city`: Branch location.
- `capacity`: Maximum number of members.
- `members`: Array containing the branch members.
- `subscriptions`: Total subscriptions sold by this branch.
- `revenue`: Total revenue generated by this branch.
- `expenses`: Total expenses of this branch.

**Important:** Each Gym object must have its own members and financial information.

---

## 4. Define Static Properties

Create the following private static properties to track the entire company:

- `totalBranches`: Total number of branches.
- `totalMembers`: Total number of members across all branches.
- `totalSubscriptions`: Total subscriptions sold across all branches.
- `totalRevenue`: Total revenue generated by all branches.
- `totalExpenses`: Total expenses across all branches.
- `allMembers`: An array containing all members from every branch.

**Hint:** Whenever a branch performs an operation, update its own properties and the corresponding company-wide static properties.

# 5. Create the Required Methods

## Challenge 1: Create a Branch

Create a method called `create()` that accepts:

- Branch name.
- City.
- Maximum capacity.

Requirements:

- Assign the received values to the current object's properties.
- Increase the company's total branches.
- Display a success message.

## Challenge 2: Add a New Member

Create a method called `addMember()` that accepts:

- Member ID.
- Member name.
- Member phone number.
- Subscription type.

Requirements:

- Check whether the branch has available capacity.
- Check whether the member already exists in the current branch.
- Calculate the subscription price based on the selected subscription type.
- Add the member to the branch's `members` array.
- Add the member to the company's `allMembers` array.
- Increase the branch's total subscriptions.
- Increase the company's total subscriptions.
- Increase the branch's revenue.
- Increase the company's total revenue.
- Increase the company's total members.
- Display a success message containing the member's name and subscription type.

**Available Subscription Types:**

- monthly
- quarterly
- yearly

**Hint:** Use `array_filter()` to check whether a member already exists.

## Challenge 3: Renew a Subscription

Create a method called `renewSubscription()` that accepts:

- Member ID.
- New subscription type.

Requirements:

- Find the member inside the current branch.
- Update their subscription type.
- Calculate the new subscription price.
- Update the member's subscription information in both arrays.
- Increase the branch's total subscriptions.
- Increase the company's total subscriptions.
- Increase the branch's revenue.
- Increase the company's total revenue.
- Display a renewal success message.

**Hint:** Use `array_filter()` to find the member and `array_map()` to update their information.

## Challenge 4: Remove a Member

Create a method called `removeMember()` that accepts a member ID.

Requirements:

- Find the member inside the current branch.
- Remove the member from the branch's `members` array.
- Remove the member from the company's `allMembers` array.
- Decrease the company's total members.
- Display a message confirming the removal.

**Hint:** Use `array_filter()` to remove the member from both arrays.

## Challenge 5: Add Branch Expenses

Create a method called `addExpense()` that accepts an expense amount.

Requirements:

- Increase the current branch's expenses.
- Increase the company's total expenses.
- Display the expense amount and branch name.

## Challenge 6: Branch Members Report

Create a non-static method called `membersReport()`.

Display a report containing all members registered in the current branch.

For each member, display:

- Member ID.
- Member Name.
- Phone Number.
- Subscription Type.
- Subscription Price.

**Requirements:**

- Use `foreach()` to display member information.
- Display the total number of members in the branch.
- Display a suitable message if the branch has no members.

## Challenge 7: Branch Financial Report

Create a non-static method called `report()`.

Display the following information about the current branch:

- Branch Name.
- City.
- Maximum Capacity.
- Current Members.
- Available Capacity.
- Total Subscriptions.
- Total Revenue.
- Total Expenses.
- Net Profit.

**Hint:** Net Profit = Revenue - Expenses.

## Challenge 8: Company Members Report

Create a static method called `companyMembersReport()`.

Display all members registered across every branch.

For each member, display:

- Member ID.
- Member Name.
- Phone Number.
- Subscription Type.
- Subscription Price.
- Branch Name.

**Requirements:**

- Retrieve members from the static `allMembers` property.
- Use `foreach()` to display the members.
- Display the total number of members across the company.

## Challenge 9: Company Financial Report

Create a static method called `companyReport()`.

Display the following information:

- Total Branches.
- Total Members.
- Total Subscriptions.
- Total Revenue.
- Total Expenses.
- Total Company Profit.

**Hint:** Use the static properties to retrieve the company's overall statistics.

## Important Notes

- Use `private` for the class properties.
- Use appropriate access modifiers for all methods.
- Use Encapsulation to protect the class data.
- Use `self::` when accessing static properties and class constants.
- Use `$this->` when accessing the current object's properties and methods.
- Do not create separate classes for members or subscriptions.
- Each member should be represented by an associative array.
- Keep the branch members and company members arrays synchronized whenever a member is added, updated, or removed.
